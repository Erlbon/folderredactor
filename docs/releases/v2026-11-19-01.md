The Ⅎolder Redactor in one window: the library tree on the left, the selected folder's note always open on the right.

**Downloads**
- `folderredactor-setup.exe`: installs the program for you alone (no administrator rights), with a Start menu entry.
- `folderredactor.exe`: one file, runs from anywhere.

An installed copy of v2026-11-08-05 updates itself to this one through Help > Check for Updates.

**What is new since v2026-11-08-05**
- **One window.** The separate notes window, its locked progress window and the review window are gone. A light on
  every folder shows its state, by shape as well as colour: a note, a draft waiting, a note you edited, or none.
- **Look Up** (Ctrl+L) drafts notes for the selected folder, or for it and the folders below. It runs in the
  background; each draft lands in the tree as it is ready and can be judged while the rest are looked up.
- **The note pane** shows the draft, else the note on disk, with Preview / Raw / Before-after (Ctrl+1/2/3). A note can
  be edited there (F4); Look Up then leaves it alone.
- **Writing:** tick boxes in the tree, one Write button for the ticked notes (Ctrl+Enter), Enter writes the selected
  draft and moves on, F8 goes to the next waiting folder. Edit > Undo takes back the last note written (with Tools >
  History on).
- **A service that is down no longer blocks the rest.** It is skipped for that run only; a pasted Wikipedia link works
  while MusicBrainz is down.
- **Help > Check for Updates** falls back to GitHub's own API when a release download fails.

The full history is in CHANGELOG.md.
