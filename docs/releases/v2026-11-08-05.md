The first release of The Ⅎolder Redactor (v0.1): a tool for the folders of a media library. It drafts the Markdown
folder notes the Pluteus media server shows, and nothing is written until you say yes.

**Downloads**
- `folderredactor-setup.exe`: installs the program for you alone (no administrator rights), with a Start menu entry.
- `folderredactor.exe`: one file, runs from anywhere.

Both update themselves through Help > Check for Updates (or the once-a-day check, off until switched on in Tools >
Preferences).

**What it does**
- **Music notes** (moved from the ɯP3 Redactor): `artist.md`, `album.md` and `about.md` for genres and collections, from
  the files' own tags (MP3, FLAC, M4A, Ogg, Opus) and from MusicBrainz, Discogs and Wikipedia, checked against the
  albums really in the folder. A genre or collection `about.md` says how the folders below it are laid out
  (`layout: letter/artist/album`), so pluteus finds the artists without scanning; a box set with disc folders gets one
  `album.md`.
- **Video notes** (moved from the Ʌideo Redactor): `series.md` and a film's `about.md` from TMDB, with a Wikipedia
  introduction when Wikidata links it to the title.
- **One review page** for both: every draft is reviewed yes/no, with Before / After for a note that is already there.
  A note a person edited is never replaced. Writes go through the Recycle Bin and can be undone from Tools > History
  (off by default).
- **The `notes` command** on the command line, in the same exe, for scripts.
- File > Import takes over the ɯP3 and Ʌideo Redactors' notes settings, lookup answers and API keys; the keys are the
  Redactor family's shared ones (Tools > API Keys).

Into a library it writes `.md` notes and nothing else. The folder-tree clean-up (the Clean Up menu) is not built yet
and is shown greyed.

The full history is in CHANGELOG.md.
