# Credits

The Ⅎolder Redactor is built on the work of a number of other projects.

## Shared foundation

- **[redactor_common](https://github.com/erlbon/redactor_common)** — the UI/logic package shared with its sibling
  tools (epub, mp3, video, cbz), including the lookup clients this program uses. See its version line in the About
  box for which build is included.

## Data

- **[MusicBrainz](https://musicbrainz.org/)** — artist and release data (CC0), looked up through the MusicBrainz web
  service; cover images from the [Cover Art Archive](https://coverartarchive.org/).
- **[Discogs](https://www.discogs.com/)** — Data provided by Discogs. This program is not affiliated with Discogs.
- **[TMDB](https://www.themoviedb.org/)** — This application uses TMDB and the TMDB APIs but is not endorsed,
  certified, or otherwise approved by TMDB.
- **[Wikipedia](https://www.wikipedia.org/)** — the introductions in folder notes are taken from Wikipedia articles,
  available under the [Creative Commons Attribution-ShareAlike License](https://creativecommons.org/licenses/by-sa/4.0/);
  each note links to its article. **[Wikidata](https://www.wikidata.org/)** (CC0) links the articles to the other
  sources.

## Libraries

- **[PyQt6](https://www.riverbankcomputing.com/software/pyqt/)** — the application framework the GUI is built on.
- **[Mutagen](https://mutagen.readthedocs.io/)** — reading the tags of audio files.
- **[keyring](https://github.com/jaraco/keyring)** — keeping the API keys in the system's credential store.
